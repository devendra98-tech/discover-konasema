# Konaseema Essence

🌴 **Coconut Heaven of Andhra Pradesh**

A premium, fully responsive Next.js 16+ website showcasing the pristine beauty, rich culture, heritage, cuisine, and nature of Konaseema - God's Own Delta.

## 🎯 Features

- **Multi-language Support** - English & Telugu (తెలుగు)
- **Premium UI Design** - Tourism/heritage portal style
- **Smooth Animations** - Framer Motion powered
- **Fully Responsive** - Works seamlessly on all devices
- **Gold + Godavari Blue Theme** - Traditional Telugu pattern accents
- **Dynamic Routing** - Place pages with detailed information
- **Image Gallery** - Masonry grid with filters and lightbox

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🌐 Language Support

The website supports two languages:
- **English** (default)
- **Telugu** (తెలుగు)

Toggle between languages using the language switcher in the navbar.

## 🎨 Theme

- **Godavari Blue**: `#1e3a8a`
- **Konaseema Gold**: `#fbbf24`
- Telugu traditional pattern accents

## 📝 Pages

- **Home** - Hero section with quick navigation links
- **Culture** - Godavari river life, boat traditions, festivals
- **Food** - Pootharekulu, Gongura, Chepa Pulusu, and more
- **Places** - Amalapuram, Dindi, Yanam, Papikondalu, Atreyapuram
- **Gallery** - Image gallery with category filters
- **About Konaseema** - Why Konaseema is special
- **Contact** - Contact form
